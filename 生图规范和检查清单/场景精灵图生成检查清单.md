# 场景精灵图生成检查清单（Agent 自检与验收）

本清单用于场景精灵图生成前的规划、生成后的质量检查，以及决定是否需要局部重绘。检查重点是素材能否被独立识别、裁切和重新组装，而不只是画面是否美观。

## A. 生成前：场景拆分规划

### A1. 素材清单
- [ ] 已列出本次场景需要生成的独立物体。
- [ ] 每个物体都有明确名称或临时编号。
- [ ] 已区分“一个整体物体”与“多个应独立的物体”。
- [ ] 没有把整片环境、整组装饰或整座区域错误地定义成一个不可拆分的大素材。

### A2. 空间层级
- [ ] 每个物体已指定远景、中景或近景。
- [ ] 远景主要承担环境轮廓和远距离氛围。
- [ ] 中景主要承担场景主体结构。
- [ ] 近景主要承担靠近镜头的装饰和前景元素。
- [ ] 层级划分依据空间深度，而不是简单按物体大小分类。

### A3. 构图与间距
- [ ] 已规划各物体的大致位置和尺寸。
- [ ] 已为每个物体预留独立的轮廓空间。
- [ ] 普通素材之间计划保留约 8–16 个源图像素的间距；复杂或细长素材留出更多空间。
- [ ] 画布边缘留有余量，避免物体被裁切。
- [ ] 没有依赖物体相互遮挡来表现空间层次。

## B. 生成后：画面与素材独立性检查

### B1. 独立性（最高优先级）
- [ ] 每个预期独立的物体都能单独辨认。
- [ ] 不同物体之间没有像素级粘连。
- [ ] 不同物体的轮廓没有相互接触。
- [ ] 没有装饰线、管线、藤蔓、光效等跨越并连接两个独立物体。
- [ ] 阴影、烟雾、粒子或背景装饰没有把多个素材连接起来。
- [ ] 物体之间的空隙没有被纹理或杂点填满。

### B2. 轮廓完整性
- [ ] 每个物体都具有完整、可识别的外轮廓。
- [ ] 没有物体被其他物体遮挡。
- [ ] 没有物体被画布边缘截断。
- [ ] 物体边缘与背景有足够区分度。
- [ ] 细小部件没有意外粘到邻近素材。
- [ ] 物体内部允许纹理、阴影和高光连接，但不同物体之间必须分离。

### B3. 分层与排布
- [ ] 远景、中景、近景的空间关系清楚。
- [ ] 同一层级的素材可以相对集中，但仍然彼此独立。
- [ ] 不同层级之间没有因排布而发生重叠。
- [ ] 物体大小、细节密度与空间距离大致协调。
- [ ] 没有为了填满画面而添加无意义的背景元素。

## C. 图像技术质量检查

### C1. 背景与透明度
- [ ] 优先使用真正的透明背景，而不是棋盘格图案。
- [ ] 若为透明 PNG，背景区域 Alpha 为 0。
- [ ] 素材主体尽量保持不透明，避免不必要的半透明边缘。
- [ ] 没有白边、黑边或背景色溢出。
- [ ] 没有背景光晕、投影或纹理干扰素材分离。
- [ ] 如果模型只能输出纯色背景，背景与所有素材主体有明显色差，且便于后续抠除。

### C2. 像素风格
- [ ] 像素网格和像素颗粒尺度统一。
- [ ] 没有抗锯齿或亚像素模糊。
- [ ] 没有柔化边缘或照片质感。
- [ ] 没有明显 JPEG 压缩伪影。
- [ ] 没有边缘半透明杂色。
- [ ] 色彩、光照方向和材质表现保持一致。
- [ ] 没有过量的孤立噪点或难以归属的碎像素。

### C3. 画面干扰项
- [ ] 没有文字、标签、编号或水印。
- [ ] 没有边框、说明文字或网格线。
- [ ] 没有棋盘格透明背景。
- [ ] 没有与素材无关的装饰性背景。

## D. 自动切分适用性检查

- [ ] 素材之间存在足够的空白或透明间隔。
- [ ] 各素材边缘对比清楚，便于自动识别。
- [ ] 没有大面积相连的背景色块把多个物体连成一个区域。
- [ ] 细长素材周围留有足够空间。
- [ ] 小型素材没有小到无法可靠识别或裁切。
- [ ] 预计每个独立物体都能被单独裁切，并保留完整边缘。

## E. 不合格处理规则

出现以下任一情况，应判定为需要修正：

**必须修正**
- 两个本应独立的素材发生粘连。
- 重要物体轮廓缺失或被遮挡。
- 物体被画布边缘截断。
- 背景或光效连接了多个独立物体。
- 透明背景实际是棋盘格或带有明显背景残留。

**建议修正**
- 素材间距不足，自动切分可能误合并。
- 细节过密，导致轮廓不清。
- 像素尺度或美术风格不统一。
- 背景干扰较多，增加后期抠图难度。

修正优先级：
1. 优先对问题素材进行局部重绘或局部修复。
2. 如果局部修复无法保证轮廓完整，再重新生成对应层级或区域。
3. 只有整体风格、构图或大量素材都不合格时，才考虑整张重生成。
4. 不要为了增加细节而牺牲素材独立性。

## F. 最终验收

- [ ] 这张图可以拆分成多个独立素材。
- [ ] 每个素材都能单独移动、缩放和旋转。
- [ ] 每个素材都能被单独命名和分类。
- [ ] 素材可以按远景、中景、近景重新分层。
- [ ] 素材适合导入场景精灵图切分编辑器进行自动识别和人工精修。
- [ ] 素材适合后续在 Godot 等游戏引擎中重新组装。

### 验收结论

- [ ] **通过**：可以进入自动切分与 Agent 标注流程。
- [ ] **有条件通过**：只有少量局部问题，修复后进入切分流程。
- [ ] **不通过**：存在严重粘连、遮挡、裁切或风格问题，需要重新生成。

**最终原则：先保证素材独立、轮廓完整、可拆分，再追求画面丰富和细节表现。**
