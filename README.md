# 精灵图切分编辑器 V7

一个**单文件 HTML** 的像素精灵图（sprite sheet）切分工具：把一张场景图切成多个独立透明 PNG，并导出 `manifest.json` 与 Agent 标注任务包。不用安装、不用构建，Chrome / Edge 打开就能用，所有图像处理都在浏览器本地完成。

**在线试用**：<https://fzqxdedafeiyu.github.io/sprite-splitter/>

## 本版（V7）做了什么

V7 基于 V6 升级，保留了自动识别、矩形 / 多边形选区、重叠区域清理、Agent 任务包与 JSON 标注导入、PNG / JSON / ZIP 导出，并新增：

- **独立精修面板**：右侧精灵列表单击选中、双击打开；面板只显示当前精灵的裁剪成品，先套用已有 Alpha / 蒙版与重叠清理结果，再供笔刷精修。
- **只作用于当前精灵的精修**：保留 / 排除笔刷与 GrabCut 收边不影响其它精灵，关闭面板后回写缩略图与导出数据。
- **滚轮直接缩放**：不需要按 Ctrl，以鼠标指针位置为参考点。
- **空格 + 拖动 / 中键拖动** 平移主画布与精修画布。
- **Ctrl+Z（macOS 为 Cmd+Z）撤销**：撤销最近一次素材 / 蒙版 / 笔迹操作，最多 60 步。

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 输入 | PNG / WebP / JPG；推荐透明背景 PNG |
| 自动识别 | 按 Alpha 透明度做连通区域分析，可调阈值、最小面积、外扩边距、4 / 8 邻域 |
| 手动选区 | 矩形框拖动追加，多边形逐点抠选（双击闭合） |
| 放大预览 | 独立预览窗口，+ / − 缩放、适应窗口、显示 / 隐藏选区框 |
| 属性编辑 | 名称、分类、描述、X / Y / 宽 / 高，均可回改 |
| 重叠清理 | 分析多个候选框相交情况，对比"清理前 / 清理后"再决定是否应用 |
| 独立精修 | 绿色保留笔刷 + 红色排除笔刷 + GrabCut 智能收边，专注单个精灵边缘 |
| 导出 | 独立透明 PNG、逐张下载、`manifest.json`、ZIP（PNG + JSON） |
| Agent 协作 | 导出任务包（原图 + 任务 JSON + 提示词），导入 Agent 返回的标注 JSON |

## 快速开始

1. 克隆或下载本仓库，用 Chrome / Edge 打开 <精灵图切分编辑器_V7_独立精修与画布操作增强版.html>（或直接用上面的在线试用链接）。
2. 点击左侧"选择 PNG / WebP / JPG"导入素材。
3. 调整 Alpha 阈值 / 最小区域面积 / 外扩边距 / 邻接方式，点击"自动识别区域"。
4. 手动补齐漏掉的区域；轮廓复杂的对象用"多边形抠选"。
5. 点击"分析重叠并预览"，确认后应用清理结果。
6. 双击右侧列表中需要精修的精灵，用保留 / 排除笔刷 + 智能收边修边缘。
7. 导出 ZIP（PNG + JSON）。

## 导出结构

```text
项目名_sprites.zip
├── sprites/
│   ├── 001_素材名称.png
│   ├── 002_素材名称.png
│   └── ...
└── manifest.json
```

每张 PNG 是独立的透明素材，`manifest.json` 保存名称、分类、描述、原图坐标等元数据。

## Agent 工作流

V7 提供的是**文件式接口**，不是 HTTP / REST API：

```text
V7 导出 Agent 任务包（source.png + agent_task.json + AGENT_PROMPT.txt）
        ↓
Agent 按 bbox 识别元素，输出 sprite-agent-result/v1 JSON
        ↓
V7 导入标注，回写名称 / 分类 / 描述 / tags / 置信度
        ↓
人工复核后导出素材
```

Agent 只负责语义（命名、分类、描述），不修改坐标、尺寸或蒙版；`sprite_id` 必须原样返回。完整协议见 <使用说明/V7_Agent阅读与自动化接口说明.md>。

## 环境与限制

- 需要较新的 Chrome 或 Edge；页面为单文件，双击打开即可，不需要本地服务器。
- **智能收边（GrabCut）依赖联网**：页面会从 OpenCV 官方地址加载 `opencv.js`；首次使用需网络可用，加载失败时矩形 / 多边形选区与基础导出仍可正常使用。
- **没有工程自动保存**：重要阶段请及时导出 ZIP / manifest；重新导入图片会清空当前选区，重新执行自动识别会重建候选列表。
- 自动识别依据 Alpha 连通区域，不具备语义理解：彼此相连的物体可能被识别成一个，需要手动拆选或精修。
- JPG 没有 Alpha 通道，自动识别通常无法按物体轮廓分离，建议先用透明背景 PNG。
- 图像全程在浏览器本地处理，不会上传到任何服务器。
