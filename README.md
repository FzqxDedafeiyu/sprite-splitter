# 像素精灵图切分编辑器 V9

一个**单文件 HTML** 的像素场景切图工具：把一张场景图切成多个独立透明 PNG，再整理成带层级、视差、锚点与分组信息的**场景布局数据**，可直接交给 Godot 或后续美术流水线。不用安装、不用起服务端，Chrome / Edge 打开就能用，图片全程在浏览器本地处理。

## V9 主要更新

相对 V7（独立精修与画布操作增强版），V9 补上了"切完之后怎么摆"这一半：

- **场景布局工作台**：左侧部件列表（勾选 / 显隐 / 锁定 / ↑↓ 调 Z 序）、右侧属性面板（空间层级、视差系数、锚点、Z 序、深度、场景位置、缩放、旋转）、中间直接拖拽定位。
- **视差模拟**：横 / 纵 / 双向模拟摄像机移动，可调幅度、显示原位置参考线和网格，用来看远景中景近景的层次对不对。
- **分组 + 批量属性**：勾选多个部件建成一组，一次统一层级、视差、深度、Z 序、缩放、旋转；不会改动各部件的位置、锚点和原始裁切框。
- **中文文件名导出**：ZIP 内路径支持 UTF-8 中文，`manifest.json` 升级为 `spatial-scene-layout/v2`（`sourceRect` / `anchor` / `layout` / `transform` / `group` / `visible` / `locked` / `file`）。
- **不透明图也能切**：先判断图片有没有透明通道；没有就按画布边缘分析浅色背景（白底、灰白棋盘格一类），再识别区域。
- 精修面板、重叠区域清理、Agent 任务包与 JSON 往返全部保留。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 输入 | PNG / WebP / JPG；优先透明 PNG，无 Alpha 时走背景色识别 |
| 自动识别 | Alpha 阈值、最小区域面积、外扩边距、4 / 8 邻域 |
| 手动选区 | 矩形框追加、多边形逐点抠选（双击闭合） |
| 检查 | 放大预览、重叠区域分析与清理预览 |
| 精修 | 绿色保留笔刷 + 红色排除笔刷 + OpenCV GrabCut 智能收边，只作用于当前部件 |
| 布局 | 层级 / 视差 / 锚点 / 深度 / Z 序 / 位置 / 缩放 / 旋转；锁定、隐藏、分组批量 |
| Agent | 导出任务包（原图 + 任务 JSON + 提示词），导入 `spatial-scene-agent-result/v2`（兼容旧版 `sprite-agent-result/v1`）回写名称与属性 |
| 导出 | 独立透明 PNG、逐张下载、`manifest.json`、ZIP（PNG + 布局数据） |

## 快速开始

1. 打开 <精灵图切分编辑器_V9_分组批量属性与中文导出版.html>（或直接用上面的在线试用链接）。
2. 导入场景图，调参数点"自动识别区域"；粘连或漏识别的手动补框 / 多边形抠选。
3. 打开放大预览检查，必要时进入独立精修面板修边缘。
4. 点"分析重叠并预览"，确认后应用清理结果。
5. 导出 Agent 任务包交给视觉 Agent 命名分类，再导入 JSON 回写。
6. 打开场景布局工作台，排层级、调视差、建组批量对齐。
7. 导出 ZIP，交给引擎或美术流水线。

大范围调整前，先导出一份 JSON / ZIP 保底。

## 操作速查

| 操作 | 方式 |
| --- | --- |
| 缩放视图 / 画布 | 鼠标滚轮 |
| 平移视图 | 空格 + 左键拖动，或鼠标中键拖动 |
| 选中 / 精修部件 | 列表单击 / 双击 |
| 删除选中部件 | `Delete` |
| 撤销 | `Ctrl+Z`（macOS `Cmd+Z`） |
| 调整 Z 序 | 部件列表的 ↑ / ↓ |
| 批量改属性 | 勾选部件 → 输入组名 → 编组 → 选组 → 设值 → 统一应用 |

## 导出结构

```text
项目名_sprites.zip
├── sprites/
│   ├── 001_素材名称.png
│   └── ...
└── manifest.json
```

`manifest.json` 为 `spatial-scene-layout/v2`：`sourceRect`（源图裁切位置）、`anchor`、`layout`（层级 / 深度 / 视差 / Z 序）、`transform`（位置偏移 / 缩放 / 旋转）、`group`、`visible`、`locked`、`file`。

## 交给 Godot

1. 解压 ZIP，`sprites/` 放进素材目录。
2. `manifest.json` 当布局数据源。
3. 按 `layout.layer` 归入远景 / 中景 / 近景的 CanvasLayer 或 Node2D。
4. 用 `transform` 还原位置、缩放、旋转，`layout.zIndex` 定绘制顺序。
5. 用 `layout.parallax` 配置 Parallax2D 或自己的相机逻辑。

编辑器只导出素材和布局数据，不生成完整 Godot 场景或脚本。

## Agent 工作流

```text
V9 导出 Agent 任务包（source.png + agent_task.json + AGENT_PROMPT.txt）
        ↓
Agent 按 bbox 识别部件，输出 spatial-scene-agent-result/v2 JSON（旧版 v1 仍可导入）
        ↓
V9 导入标注，回写名称 / 分类 / 描述 / tags / 层级与布局建议
        ↓
人工复核后导出素材
```

约束：`sprite_id` 必须原样返回；Agent 只负责语义与属性建议，不改裁切边界；`sourceRect` 是源图坐标，人工移动、缩放、旋转不应覆盖它。

## 环境与限制

- 需要较新的 Chrome 或 Edge；单文件双击即可，不需要本地服务器。
- **智能收边依赖联网**：从 OpenCV 官方地址加载 `opencv.js`，首次使用需网络可用；加载失败时其余功能照常。
- 没有工程自动保存，重要阶段请导出 ZIP / JSON 备份。
- 自动识别是基于像素连通与背景色分析，不理解语义：互相接触的物体会被并成一个，必须人工复核。
- 逐张下载 PNG 时，浏览器可能询问是否允许多文件下载。
- ZIP 内中文文件名需要支持 UTF-8 的解压工具（新版 7-Zip、Windows 11 资源管理器均可）。
