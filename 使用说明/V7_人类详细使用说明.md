# 精灵图切分编辑器 V7｜人类详细使用说明

版本：V7\
运行方式：本地浏览器打开单文件 HTML\
主要用途：把一张场景图切成多个独立透明 PNG 精灵，并生成 manifest JSON。

## 1. V7 能做什么

-   导入 PNG、WebP、JPG 图片；
-   根据 Alpha 透明度自动识别连通区域；
-   手动追加矩形选区；
-   使用多边形轮廓抠出不规则对象；
-   放大预览自动切分结果；
-   对选中精灵进行独立精修；
-   使用绿色保留笔刷、红色排除笔刷辅助智能收边；
-   分析并预览选区重叠清理结果；
-   编辑名称、分类、描述和原图坐标；
-   导出独立透明 PNG、ZIP 和 manifest JSON；
-   导出 Agent 任务包并导入 Agent 标注结果。

> 推荐输入透明背景 PNG。JPG 不包含 Alpha
> 透明通道，自动识别通常无法按物体轮廓分离。

## 2. 启动与导入图片

1.  将 `精灵图切分编辑器_V7_独立精修与画布操作增强版.html` 保存到本地。
2.  使用 Chrome 或 Edge 打开该 HTML 文件。
3.  点击左侧"选择 PNG / WebP / JPG"。
4.  选择需要切分的场景图。
5.  图片加载后，中间主画布显示原图，右侧精灵列表为空。

编辑器主要在浏览器本地处理图像。V7 页面会从 OpenCV 官方地址加载
OpenCV.js
以执行智能收边，因此首次使用智能精修时需要网络可用；普通导入、框选和基础导出不依赖
Agent 服务。

## 3. 自动识别区域

左侧"② 自动识别"区域提供四个参数：

### Alpha 阈值

-   默认值：16。
-   像素 Alpha 大于该阈值时，视为有效像素。
-   阈值调高：忽略更透明的边缘像素，可能减少淡淡的光效或半透明噪点。
-   阈值调低：保留更多半透明像素，但可能把弱透明连接也识别出来。

### 最小区域面积

-   默认值：80 px。
-   小于该像素面积的连通区域会被忽略。
-   调高可过滤小噪点；调低可保留细小装饰、粒子或小物件。

### 外扩边距

-   默认值：4 px。
-   在识别出的区域边界外增加一定像素的矩形留白。
-   边距过大会让邻近物体进入候选框；后续可通过蒙版或精修处理。

### 邻接方式

-   8 邻域：上下左右及四个对角方向接触都算连通。
-   4 邻域：仅上下左右接触算连通。
-   若两个对象只在角落相接，可尝试 4 邻域。

### 操作步骤

1.  调整参数。
2.  点击"自动识别区域"。
3.  等待识别完成。
4.  查看中间画布上的选区框和右侧列表。
5.  若物体粘连、漏识别或出现噪点，可调整参数重新识别，或使用手动选区补充
    / 修正。

注意：自动识别依据 Alpha
连通区域，不具备物体语义理解能力。彼此相连的鱼、建筑、光效可能被当作同一个连通区域。

## 4. 放大预览与主画布操作

### 放大预览

-   点击左侧"放大预览"打开独立预览窗口。
-   可使用窗口底部的"＋ / －"缩放。
-   "适应窗口"让整张原图适配预览区域。
-   "显示/隐藏选区框"控制是否显示候选边界。
-   也可以在预览区滚动鼠标滚轮缩放。

### 主画布缩放

-   鼠标滚轮：以鼠标指针为中心缩放。
-   左侧缩放滑块：设置缩放百分比。
-   主画布工具栏"＋ / －"：调整缩放。
-   "适应画布"：让整张图片尽量适配主画布。
-   "重置视图"：重置平移位置并重新适应画布。

### 主画布平移

-   按住空格键，同时按住鼠标左键拖动；
-   或按住鼠标中键拖动。

### 显示选项

-   "显示/隐藏框"：隐藏或显示所有选区边框。
-   "显示/隐藏原图"：隐藏或显示底图，便于观察选区蒙版效果。

## 5. 手动追加矩形选区

自动识别完成后仍然可以继续添加选区。

1.  点击"手动追加矩形选区"。
2.  在主画布上按住鼠标左键拖动，框出目标区域。
3.  松开鼠标后，新选区会加入右侧精灵列表。
4.  可以连续追加多个矩形。
5.  再次点击该按钮或点击"取消追加选区"退出模式。

新增矩形会作为独立候选区域，不会因为自动识别已经完成就禁止添加。

### 移动与调整大小

-   选中一个精灵后，在其框内拖动可移动选区。
-   拖动选区右下角控制点可调整宽高。
-   右侧属性面板也可以直接修改 X、Y、宽度和高度。

注意：矩形框只定义裁切范围，不一定代表框内所有像素都属于目标物体。若矩形覆盖到邻近对象，应使用重叠清理或独立精修进一步处理。

## 6. 多边形抠选

适合轮廓不规则、周围有邻近元素的对象。

1.  点击"多边形抠选"。
2.  沿目标物体边缘逐点单击，依次添加轮廓点。
3.  尽量贴合物体边缘，避免把旁边对象圈入。
4.  至少添加 3 个点。
5.  双击结束并闭合多边形。
6.  完成后，新精灵会出现在右侧列表中；多边形外部像素在导出时透明。

再次点击多边形按钮可退出模式。多边形选区的边界点定义局部轮廓，不是矩形裁切框的装饰线。

## 7. 精灵列表与属性编辑

右侧"精灵列表"显示每个候选的缩略图、名称、尺寸和分类。

-   单击列表项目：选中该精灵。
-   双击列表项目：打开该精灵的独立精修面板。
-   单击后，右侧"选中区域属性"显示当前对象信息。

### 可编辑属性

-   名称：建议使用清晰、可区分的中文名称。
-   分类：建议使用
    `character`、`creature`、`prop`、`architecture`、`background`、`terrain`、`vegetation`、`effect`、`UI`、`other`。
-   描述 / 备注：记录用途、外观或识别注意事项。
-   X / Y：选区左上角在原图中的坐标。
-   宽度 / 高度：选区尺寸，单位均为原图像素。

修改后点击"应用坐标"保存。点击"定位到选中框"可将主画布滚动到当前选区附近。

删除选中区域： - 点击左侧"删除选中框"，或按键盘 Delete。 -
删除后该候选不会进入后续导出。

## 8. 重叠区域智能清理

用于检查多个候选矩形框相交、相邻物体可能被重复裁入的情况。

1.  完成自动识别和手动追加后，先检查所有候选框。
2.  点击"分析重叠并预览"。
3.  在弹出的窗口中对比"清理前"和"清理后（待应用）"。
4.  查看摘要与冲突提示。
5.  确认结果正确后，点击"应用清理结果"。
6.  如果结果不符合预期，点击"取消，不修改素材"。

建议： - 先做重叠分析，再逐个打开独立精修面板。 -
对不确定的像素归属应优先人工检查，不要只凭矩形框是否相交判断。 -
手动矩形与自动识别区域重叠时，尤其要检查清理后的结果。 -
如果黄色手动框对应的区域被异常裁掉或保留了邻居，不要直接应用；取消后改用多边形选区或单独精修。

## 9. 独立精修面板

独立精修面板是 V7
的重点功能。双击右侧列表中的精灵即可打开；也可先单击选中，再点击左侧"打开单独精修面板"。

面板会把当前选中精灵放大显示。其目标是基于当前已有蒙版 /
重叠清理结果继续精修，而不是在主画布上直接涂改整张原图。

### 笔刷模式

-   **保留笔刷（绿色
    +）**：在目标主体内部涂抹，提示算法这些像素必须保留。
-   **排除笔刷（红色
    −）**：在误切入的邻近物体、背景或杂点上涂抹，提示算法这些像素应排除。

### 建议操作流程

1.  双击右侧精灵列表中的目标。
2.  确认精修对象名称和尺寸。
3.  调整笔刷大小。
4.  点击"保留笔刷 (+)"，在主体内部画少量绿色笔迹。
5.  点击"排除笔刷 (−)"，在应去掉的周边区域画红色笔迹。
6.  点击"运行智能收边"。
7.  检查输出轮廓；如不理想，可继续补充笔迹再次运行。
8.  点击"完成并返回"。

### 其他按钮

-   "清除笔迹"：清除当前笔刷提示，不等同于恢复图像。
-   "撤销精修"：撤销最近一次智能蒙版结果。
-   "关闭面板" / "完成并返回"：退出独立精修面板。

注意： - 智能收边依赖 OpenCV.js / GrabCut，首次运行需要浏览器成功加载
OpenCV。 - 保留和排除笔迹应画在明确区域，避免过度涂抹。 -
运行后务必检查边缘，尤其是细触须、半透明光效、像素风细小连接处。 - V7
的精修是对透明蒙版进行处理，不是重绘或生成新像素。

## 10. 撤销与快捷键

-   `Ctrl + Z`（Mac 可用 `Cmd + Z`）：撤销上一步已记录操作。
-   `Delete`：删除当前选中的精灵。
-   `Space + 鼠标左键拖动`：平移主画布 / 精修画布。
-   `鼠标中键拖动`：平移画布。
-   `鼠标滚轮`：缩放主画布或精修画布。

撤销历史最多保留 60
步。精修面板另有"撤销精修"按钮，用于撤销最近一次蒙版精修。

## 11. Agent 元素识别与标注

V7 提供文件式 Agent 工作流：

### 导出任务

1.  先完成候选选区创建。
2.  点击"导出 Agent 任务包"。
3.  浏览器下载 ZIP 文件。
4.  ZIP 内包含 `source.png`、`agent_task.json`、`AGENT_PROMPT.txt`。

### 让 Agent 标注

把 ZIP 提供给视觉 Agent，让其按 `sprite_id` 识别每个候选元素，并返回
`sprite-agent-result/v1` 格式 JSON。

### 导入标注

1.  点击"导入 Agent 标注"。
2.  选择 Agent 返回的 JSON。
3.  查看右侧列表和属性面板，确认名称、分类和描述是否正确。

当前 V7 的 Agent 接口不是在线 API；Agent
不会自动在切割过程中运行，也不会直接修改选区几何。详细 JSON
协议见配套《V7 Agent 使用说明》。

## 12. 导出最终素材

确认所有选区、蒙版、命名与分类后再导出。

### 导出 ZIP（推荐）

点击"导出 ZIP（PNG + JSON）"，生成 ZIP，内部结构大致如下：

``` text
项目名_sprites.zip
├── sprites/
│   ├── 001_素材名称.png
│   ├── 002_素材名称.png
│   └── ...
└── manifest.json
```

每张 PNG 为独立透明素材；manifest.json 保存素材元数据。

### 仅导出 JSON

点击"导出 JSON"，下载 manifest 文件，不包含 PNG 图片。

### 逐张下载 PNG

点击"逐张下载 PNG"，浏览器会连续触发多张 PNG
下载。浏览器可能询问是否允许多文件下载；如有提示，请允许。

## 13. 推荐的完整操作顺序

1.  导入原始透明 PNG。
2.  调整 Alpha 阈值、最小面积、外扩边距和邻接方式。
3.  自动识别区域。
4.  打开放大预览，检查整体切分。
5.  手动追加漏掉的区域；对复杂轮廓使用多边形抠选。
6.  检查重叠区域，预览并确认清理结果。
7.  对边缘复杂或相邻物体较多的精灵逐个双击精修。
8.  导出 Agent 任务包，让 Agent 命名、分类、描述。
9.  导入 Agent 标注并人工抽查。
10. 最后检查每个精灵的透明边缘、尺寸、名称和分类。
11. 导出 ZIP（PNG + JSON）。

## 14. 常见问题排查

### 自动识别把两个对象识别成一个

-   尝试切换 8 邻域 / 4 邻域；
-   适当提高 Alpha 阈值；
-   使用多边形抠选拆出独立对象；
-   对粘连边缘使用独立精修。

### 自动识别漏掉小元素

-   降低最小区域面积；
-   降低 Alpha 阈值；
-   手动追加矩形或多边形选区。

### 手动矩形包含邻近物体

-   先取消不理想的重叠清理结果；
-   使用多边形抠选限定轮廓；
-   或双击该精灵，在精修面板用红色排除笔刷去除邻居。

### 重叠预览结果不符合预期

-   不要应用错误结果；
-   取消预览；
-   检查手动框与自动框的关系；
-   优先使用多边形或单独精修；
-   对手动矩形边界特别敏感的素材，应用前务必逐项核对。

### 智能收边按钮无反应或失败

-   确认网络可用，OpenCV.js 已加载；
-   等待页面完全加载后再试；
-   刷新页面重新打开 HTML；
-   如果仍失败，可先使用矩形 / 多边形选区完成基础切分。

### ZIP 下载后找不到文件

-   检查浏览器下载列表；
-   确认是否拦截了多个文件下载；
-   确认浏览器没有将下载保存到其他目录。

## 15. 使用注意事项

-   编辑器当前没有工程文件自动保存机制。重要阶段应及时导出素材 ZIP /
    manifest。
-   重新导入图片会清空当前编辑器中的选区状态。
-   重新执行自动识别会重建候选列表；如已完成大量手动调整，先导出备份。
-   Agent 标注与选区几何分离。Agent 不应改变 ID 对应关系、坐标或蒙版。
-   最终导出前应逐个检查透明背景、边缘完整性和相邻物体是否被误带入。
