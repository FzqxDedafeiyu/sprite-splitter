## 测试中确认的参数行为（不应误登记为缺陷）

- **A-002**：浅色背景亮度阈值调整对真实像素接触无帮助；Alpha 阈值 47 后，已观察到的粘连对象可以切开。
- **A-006**：默认 Alpha 下四块分区牌被微光连成整体；Alpha 阈值调整至 **47** 后成功分离，结论为“调整后通过”，不是识别失败。
- **A-004**：Alpha 47 能减少识别区域数量，但会削薄、损伤柔和光晕。识别阶段阈值与导出阶段保留原始低 Alpha 像素应在 V10 中解耦，这是设计建议，不是 V9 已验证能力。
- **A-005**：最小区域面积可在保留小目标与过滤碎片之间调节；滑块缺少精确数值输入，目标 10px 难以设定。
- **A-003**：不需要重复碎片压力测试；A-005 已覆盖最小面积过滤的主要验证目标。

## 风险分级说明

- 高：可能造成编辑数据丢失、错误写入或主要操作中断。
- 中：可能造成局部编辑错误、工作流受阻或外部依赖不可用。
- 低/待评估：入口可发现性或体验问题，需结合实际场景定级。

## 当前结论

用户实测问题与静态源码风险分别登记。A-006 已明确为调整 Alpha 至 47 后通过；A-009 往返导入已通过；A-010 已产出真实导出样本但完整性专项检查未完成。放大后显示不清晰的问题属于新增用户报告，尚未独立复现。静态风险不等于已复现 BUG。
