## 自动化测试候选

当前仓库为单文件 HTML，未发现测试框架或自动化脚本。以下是候选方向，不代表已实现：

1. **纯函数单测**：矩形交集、边界 clamp、4/8 邻域连通域、Manifest 序列化、Agent schema/ID 匹配、CRC32/ZIP 头字段。
2. **像素算法测试**：使用合成 RGBA buffer 对 Alpha 阈值、浅色边缘 flood-fill、最小面积、外扩边距做确定性断言。
3. **浏览器端集成测试**：导入图片、自动识别、增删选区、修改属性、场景检视、下载文件。
4. **Golden image 测试**：固定素材和期望 PNG/Manifest，比较像素或哈希；对算法阈值变化需显式更新基准。
5. **持久化契约测试**：当前 V9 无自动保存，不应编写“刷新后自动恢复”的通过用例；仅验证实际支持的文件导入/导出行为。
