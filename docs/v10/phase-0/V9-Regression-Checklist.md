## 结果状态定义

- **通过**：用户按测试素材执行，结果符合目标。
- **调整后通过**：默认参数未达到目标，调整参数后达到目标。
- **部分通过 / 有限制**：核心能力有效，但存在明确边界或质量折衷。
- **未通过**：已执行且结果未达到目标。
- **待验证**：未执行、缺少证据或仍需复现。
- **不适用 / Agent 负责**：不属于 V9 自动识别能力范围，交由 Agent 语义标注。

### 其他人工观察

- 纯绿色不透明 RGB 背景被整体识别为一个区域；调整浅色背景亮度阈值和 Alpha 阈值均无效。当前 V9 的浅色边缘背景排除不是通用绿幕抠图。
- 选区放大时，精灵显示随放大逐渐变得难以辨认，缩小时反而更清楚。此为用户观察到的显示/缩放异常，尚未独立复现和定位；见 `V9-Known-Issues.md`。
- 自动识别后直接手工新增框与合并已有精灵不是同一操作；新增框不会自动替换或合并原有小框。

## 自动化测试候选

当前仓库为单文件 HTML，未发现测试框架或自动化脚本。以下是候选方向，不代表已实现：

1. 纯函数单测：矩形交集、边界 clamp、4/8 邻域连通域、Manifest 序列化、Agent schema/ID 匹配、CRC32/ZIP 头字段。
2. 像素算法测试：合成 RGBA buffer 对 Alpha 阈值、浅色边缘 flood-fill、最小面积、外扩边距做确定性断言。
3. 浏览器端集成测试：导入图片、自动识别、增删选区、修改属性、场景检视、下载文件。
4. Golden image 测试：固定素材和期望 PNG/Manifest，比较像素或哈希。
5. 持久化契约测试：当前 V9 无自动保存，不应编写“刷新后自动恢复”的通过用例。
