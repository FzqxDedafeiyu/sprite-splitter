## 素材交付建议

- 尽量提供原始 PNG/WebP/JPG，不要通过聊天软件二次压缩。
- 对关键素材附一份简短说明：预期精灵数量、应保留/删除区域、期望层级或特殊边缘。
- A-009 的 JSON 必须保留原始 sprite_id；不要手工重新编号。
- A-010 应注明由哪个 V9 文件版本、哪个浏览器和哪次导出生成。
- 如素材含敏感内容，请先做脱敏处理。

## 当前可用性结论

本次静态检查的仓库文件树没有发现上述专用测试素材。V9 HTML、README 和使用说明不等同于测试素材。除非用户提供或后续从实际 V9 操作中导出，A-001 至 A-010 均不能标记为已具备。
