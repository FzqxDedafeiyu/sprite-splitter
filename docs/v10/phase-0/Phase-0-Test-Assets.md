- A-002 与 A-006 的 Alpha 阈值 47 结论来自用户实际操作；不要把 A-006 继续描述为无法分离。
- A-003 的碎片过滤不再重复压测；最小区域面积的效果由 A-005 覆盖。

- A-010 的“已产出 ZIP”不等于 CRC、跨解压工具、多边形和 mask 的完整导出矩阵均已验收。
- 纯绿色不透明 RGB 背景的失败观察另记在 V9-Known-Issues.md，不将其与真实 Alpha 素材混淆。
