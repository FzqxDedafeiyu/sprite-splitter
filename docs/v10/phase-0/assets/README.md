## Set A — 生图 + 真实 Alpha

- **来源**：千问 `qwen-image-3.0-pro` 生成（2026-11-26，Harness 免费额度，不占 Credits）。
- **处理**：生图时统一要求纯绿幕背景，再用「从画面四边泛洪」的方式抠背景，输出**真实 Alpha 通道**（不是棋盘格画在 RGB 里）。
- **A-004**：软边无法泛洪，Alpha 由辉光亮度导出——是合成夹具，可测阈值，但不代表真实烟雾/玻璃的色偏。
- **A-008**：已由人工替换为一张 1672×941 的分层场景（含真实 Alpha，约 44% 不透明 / 47% 透明），用于场景布局测试。

## Set B — 早期概念图裁切（非基准）

按包内 `README.txt`，这批是同一张概念图的近似裁切，**只适合做冒烟测试，不是权威基准**：

- 背景是深色渐变，**不是真透明**——不能用于 A-003 的真实 Alpha 验收。
- A-002 含邻近物体，但缺少严格的角接触用例。
- A-007 是一张含四个姿势的图，不是四个独立帧文件。
- A-008 是紧凑场景插画，不是严格分层的视差源。

## 怎么选

| 测试目标 | 用哪套 |
|---|---|
| 真实 Alpha、背景抠除、透明导出（A-003） | **必须 Set A** |
| 最小面积阈值、碎点过滤（A-005） | Set A（碎点数量可控），Set B 仅作补充 |
| 软边 / 半透明阈值（A-004） | 两套都可，Set A 的 Alpha 是合成值 |
| 场景布局、层级、视差（A-008） | 两套都可，Set A 已换成真实分层场景 |
| 快速冒烟、导入导出通链路 | Set B 够用（体积小） |
| 4 / 8 邻域的角接触 | **两套都不严格**，建议另做一张专门的对角接触图 |
