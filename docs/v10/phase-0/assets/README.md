### A-002 / A-006 的实测依据（阈值 alpha > 16）

- 整张表：**8 邻域 86 个分量、4 邻域 98 个**，差 12 个 —— 画面里确有对角接触，可用于 4/8 邻域对比。
- 第二大分量 bbox **784×218**，横跨「知识区 / 动画区 / 游戏区 / 美食区」四块牌子：四块被周围微光连成一片，自动识别只给一个框。
- A-006 正是这块的裁剪：8 邻域仅 **6 个分量**，最大那个仍是四牌合并体，天然要求人工拆分。

## Set B — 早期概念图裁切（非基准）

按包内 `README.txt`，这批是同一张概念图的近似裁切，**只适合做冒烟测试，不是权威基准**：

- 背景是深色渐变，**不是真透明**——不能用于 A-003 的真实 Alpha 验收。
- A-002 含邻近物体，但没有严格的对角接触用例。
- A-007 是一张含四个姿势的图，不是四个独立帧文件。
- A-008 是紧凑场景插画，不是严格分层的视差源。

## 怎么选

| 测试目标 | 用哪套 |
|---|---|
| 真实 Alpha、背景抠除、透明导出（A-003） | **必须 Set A** |
| 4 / 8 邻域、对角接触合并（A-002） | **Set A**（86 vs 98 分量差，Set B 无对角接触） |
| 自动识别合并后手工拆分（A-006） | **Set A**（四牌合并体） |
| 最小面积阈值、碎点过滤（A-005） | Set A 为主，Set B 作补充 |
| 软边 / 半透明阈值（A-004） | 两套都可，Set A 的 Alpha 是合成值 |
| 场景布局、层级、视差（A-008） | 两套都可，Set A 是真实分层场景 |
| 快速冒烟、导入导出通链路 | Set B 够用（体积小） |

## 已知偏差

- Set A 中 A-003 / A-005 / A-007 保留了少量碎点（80 / 70 / 1 个），用于最小面积阈值测试。
- A-004 的软 Alpha 由亮度合成，可测阈值，不代表真实烟雾/玻璃的色偏。
- A-002 / A-006 / A-008 的 Alpha 最大值是 253 而非 255（导出时的轻微缩放），阈值 16 下不受影响。
- 严格的大块物体对角接触仍缺一个专门用例（现有差集集中在细节与微光区域）。
